# Sentiment Classification using Machine Learning

## 📌 Overview
This project implements a sentiment analysis model to classify text data into positive and negative categories. It uses a custom CSV dataset, applies text preprocessing, and trains a Logistic Regression classifier on TF-IDF features.

## 🛠️ Technologies Used
- Python  
- scikit-learn  
- pandas  
- numpy  

## 📂 Dataset
- Format: CSV file containing labeled text data about movies reviews(positive/negative).  
- Preprocessing included: text cleaning, tokenization, stopword removal.

## ⚙️ Methodology
1. Loaded and preprocessed the dataset.  
2. Applied TF-IDF vectorization for feature extraction.  
3. Trained Logistic Regression classifier on processed features.  
4. Evaluated performance using accuracy score.  

## 📊 Results
- Achieved **~90+% accuracy** on the test dataset.
